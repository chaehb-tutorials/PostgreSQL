# 03.SynchDB
## 03.01 Install Extension to PostgreSQL

> Install dependencies
```bash
sudo apt install libprotobuf-c-dev
```
> /etc/ld.so.conf.d/java.conf
```bash
/usr/lib/jvm/default-java/lib
/usr/lib/jvm/default-java/lib/server
```
> run ldconfig
```bash
sudo ldconfig
```
> Download synchdb from github 
- check synchdb, postgresql version, ubuntu distribution
```bash
sudo dpkg -i xxxxx.deb
```

## 03.02 Load SynchDB Extension to PostgreSQL database
```sql
CREATE EXTENSION pgcrypto;
CREATE EXTENSION IF NOT EXISTS synchdb CASCADE;
```
