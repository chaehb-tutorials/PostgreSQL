# 02. Install and Setup
## 02.01 Install Extension to PostgreSQL
> After installing PostgreSQL (ex) version 17.x
```bash
sudo apt install postgresql-17-pgvector pgvectorscale-postgresql-17 postgresql-17-age
```
## 02.02 Setup Extension to Database
> in your `database`
```postgresql
db_name=# CREATE EXTENSION IF NOT EXISTS age CASCADE;
```

## 02.03 For every connection of AGE you start, you will need to load the AGE extension.
```PostgreSQL
db_name=# LOAD 'age';
db_name=# SET search_path = ag_catalog, "$user", public;
```
