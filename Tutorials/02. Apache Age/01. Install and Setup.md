# 02. Apache Age
## 02.01 Install Extension to PostgreSQL
> After installing PostgreSQL (ex) version 18.x
> install from package manager
```bash
# currently not supported 2025.12.30
#sudo apt install postgresql-18-pgvector pgvectorscale-postgresql-18 postgresql-18-age
```
> Build from source
```bash
# if needed
sudo apt install postgresql-18-pgvector pgvectorscale-postgresql-18
#download branch PG18 from github
git clone --branch PG18 --single-branch https://github.com/apache/age.git
# install dependencies
sudo apt install build-essential libreadline-dev zlib1g-dev flex bison
cd age
pg_config
make
sudo make install
```
## 02.02 Setup Extension to Database
> in your `database`
```sql
CREATE EXTENSION IF NOT EXISTS age CASCADE;
```

## 02.03 For every connection of AGE you start, you will need to load the AGE extension.
```sql
LOAD 'age';
SET search_path = ag_catalog, "$user", public;
```
